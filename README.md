​Audit the Government
​Moving past administrative illusion through raw data transparency, cryptographic verification, and local-first execution.
​The Core Mission
​Modern governance and institutional compliance often rely on an illusion: a black box of opaque disclosures, complex bureaucratic formatting, and unchecked self-reporting.
​Audit the Government is an open-source, local-first framework designed to shatter that illusion. By shifting the burden of proof from institutional promises to mathematical verification, this project provides the tools necessary to ingest, parse, and audit public datasets, regulatory filings, and financial ledgers without relying on third-party servers or curated narratives.
​Technical Principles
​Zero-Dependency Local Execution: Built entirely on standard Python libraries (sqlite3, hashlib, json, csv), ensuring complete reproducibility on any local environment—from desktop workstations to mobile terminal toolchains.
​Cryptographic Provenance: Every record, ledger state, and verification output is chained and validated using SHA-256 hashing (file_provenance.db, capital_audit_ledger.db), guaranteeing that data has not been altered, tampered with, or biased in transit.
​Unbiased Simulation Pipelines: Automated regex keyword scanners and asset verification scripts cross-reference public institutional data against localized compliance baselines to expose structural gaps and drift.
